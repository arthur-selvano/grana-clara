# GranaClara 💚

Aplicação de controle financeiro pessoal para registrar receitas e despesas, acompanhar o saldo e visualizar informações financeiras em um dashboard.

## Tecnologias

- Java e Spring Boot
- Maven
- React e Vite
- Tailwind CSS
- Recharts
- PostgreSQL
- JUnit e testes de integração

## Funcionalidades

- Cadastro, edição, listagem e exclusão de transações
- Resumo de receitas, despesas e saldo
- Filtros de transações
- Dashboard com gráficos financeiros
- Modos claro e escuro

## Arquitetura e aprendizado

Projeto desenvolvido com foco no estudo dos princípios da **Clean Architecture**, separação de responsabilidades, organização das regras de negócio e testes automatizados.

A inteligência artificial foi utilizada como ferramenta de apoio durante o desenvolvimento, auxiliando na implementação, na resolução de problemas e na compreensão das decisões técnicas.

O principal objetivo foi aprofundar o entendimento de arquitetura de software e praticar conceitos de desenvolvimento full stack.

## Como executar

### Backend

Configure o PostgreSQL e as variáveis de ambiente necessárias.

```bash
mvn spring-boot:run
```

Execute o comando na pasta do backend.

### Frontend

```bash
npm install
npm run dev
```

Execute os comandos na pasta do frontend.
