# GranaClara

Uma aplicação full-stack para gerenciamento de finanças pessoais, desenvolvida com React e Java. O back-end disponibiliza uma API REST para gerenciamento de transações financeiras, utilizando Spring Boot e PostgreSQL.

## Tecnologias utilizadas
- Java 21
- Spring Boot
- React
- PostgreSQL
- Docker
- Maven

## Status do projeto
Em desenvolvimento. O back-end permite cadastrar, listar, consultar e excluir transações financeiras. A atualização de transações e novas funcionalidades estão planejadas para as próximas etapas.
